# TOMORI IDEA 利用説明書

思いついたアイデアを、書き留めて・整理して・あとで探せるアプリです。ログインや登録は不要です。

## ⚠️ 大切なお知らせ(データの保存場所)

- アイデアは**お使いの端末のブラウザ内にだけ**保存されます。サーバーには送信されません。
- **端末やブラウザを変えると、データは共有されません。** (例: iPhoneで書いたアイデアはPCでは見えません。SafariとChromeの間でも共有されません)
- ブラウザの「閲覧履歴・サイトデータの削除」を行うと、アイデアも**消えてしまいます**。
- プライベートブラウズ中は保存できない、または閉じると消える場合があります。
- 現在、バックアップや引き継ぎの機能はありません。大切な内容は別途控えておくと安心です。

## 使い方

### アイデアを登録する
1. 一覧画面の下にある **「＋ 新しいアイデアを書く」** を押します。
2. **タイトル**(必須・100文字まで)と**内容**(自由記述・5000文字まで)を入力します。
3. **カテゴリ**(ビジネス / 仕事 / 暮らし / その他)と**ステータス**(アイデア / 検討中 / 実行済み)を選びます。
4. **「保存する」** を押すと一覧に追加されます。登録日時・更新日時は自動で記録されます。

タイトルが空のままだと保存できません(エラーが表示されます)。

### 一覧を見る
- 新しく登録したものが上に並びます。
- 各カードにカテゴリ・ステータス・登録日時が表示されます。
- カードをタップすると詳細画面が開きます。

### 編集する
詳細画面で **「編集する」** → 内容を変更 → **「保存する」**。更新日時が変わります。

### 削除する
詳細画面で **「削除」** → 確認画面で **「削除する」**。やめる場合は **「キャンセル」**。削除したアイデアは元に戻せません。

### 探す・絞り込む
- 一覧上部の検索欄に言葉を入れると、**タイトルと内容**から探します。スペースで区切ると、すべての言葉を含むものだけが表示されます。
- **カテゴリ**・**ステータス**のボタンで絞り込めます(もう一度押す、または「すべて」で解除)。検索と絞り込みは同時に使えます。

### ホーム画面に追加(iPhone)
Safariで開き、共有ボタン →「ホーム画面に追加」。アプリのように起動できます(データは同じSafariの保存領域を使います)。

## よくある質問

**Q. データが消えました。** サイトデータの削除、別のブラウザ/端末で開いた、プライベートブラウズ、のいずれかが考えられます。

**Q. 「保存に失敗しました」と出ます。** ブラウザの保存領域がいっぱい、またはプライベートモードの可能性があります。通常モードで開き直してください。
